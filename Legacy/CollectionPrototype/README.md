solution, runtime, or publish output. The obsolete prototype project file was
removed so the application has a single .csproj; the historical source remains.

Keep this archive and the original desktop checker until mixed-target intranet
acceptance is complete. Neither historical results nor the new build prove WMI
permissions on actual servers.
